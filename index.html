Nummerkollen

Välj en katalog. Appen läser alla jpg- och png-filer vars namn börjar med ett tal följt av komma, t.ex. 2654, hej kalle.jpg. Har filerna ett prefix före numret (t.ex. A_2654, …) väljer du det nedan.

Prefix:
Tomt = lägsta/högsta funna nummer
Flera intervall skrivs med komma, t.ex. 1900-1999, 2020-2030. Dessa tal visas inte som saknade.

Högerklicka på ett filnummer för att byta namn på filen. Ctrl+högerklick flyttar filen till mappen _Raderade (Chrome/Edge).

Dubbletter

Saknade nummer

Klicka på ett nummer för att kopiera det (vid en följd kopieras det lägsta).

Årtal i filnamn

Kontrollerar texten efter sista kommat. Tillfälligt: xxxx eller 0000 (platshållare, visas i eget filter). Rätt format: 1984, c1984, 1980t, c1980t, 1970-1990, 1970t-1990t, text inom parenteser ( ) ignoreras, samt med förord: före 1884, innan 1935, troligen 1993, mellan 1956-1967, efter 1975, sent 1890t, mitten 1960t, tidigt 1980t.

Ignorerade bildfiler

jpg/png-filer vars namn inte börjar med (valt prefix och) tal + komma. Klicka ✎ eller högerklicka på namnet för att byta namn, så att filen blir godkänd.

Bilddubbletter

Jämför själva bilderna (jpg/png), inte bara namnen. Identiska filer hittas exakt. Liknande bilder hittas genom att jämföra ett litet visuellt fingeravtryck av varje bild. Inget laddas upp och inget ändras eller raderas.

Lägre = strängare (färre falska träffar), högre = lösare

Sök i filnamn

Sök på text i filnamnen (jpg/png), till exempel ett felstavat ord. Markera de filer du vill rätta och klicka "Rätta markerade", eller klicka ✎ vid en enskild fil. Du skriver själv det rättade namnet.

Flytta till _Raderade?

Filen flyttas till mappen _Raderade i den valda katalogen. Den raderas inte, och kan återställas med "Ångra" eller genom att du själv flyttar tillbaka den.
